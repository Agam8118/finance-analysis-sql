# Personal Finance & Expense Analytics

A SQL portfolio project built with MySQL 8.0 to explore personal finance, spending patterns, and monthly budgeting through relational database design and analytical queries.

## Overview

This project models financial transactions, income, expense categories, and monthly budgets. It aims to demonstrate practical SQL skills through data organization, reporting, and financial analysis.

## Objectives

- Design a relational database with appropriate primary and foreign keys.
- Store and analyze income and expense transactions.
- Identify spending patterns across categories and months.
- Compare actual spending with budget limits.
- Develop reusable SQL reports and views.

## Technology Stack

- **Database:** MySQL 8.0
- **Tools:** MySQL Workbench, Git, GitHub
- **Language:** SQL

## Planned Analysis

1. Total income, expenses, and net balance.
2. Spending by category.
3. Monthly spending trends.
4. Users exceeding budget limits.
5. Highest-spending categories and transaction summaries.

## How to Run

1. Install MySQL 8.0 or a compatible version.
2. Clone this repository.
3. Open the SQL scripts in MySQL Workbench.
4. Run `01_create_tables.sql`.
5. Run `02_insert_data.sql`.
6. Execute queries from `03_analysis_queries.sql`.
7. Create and test views using `04_views.sql`.

Run the scripts in the order listed above.
